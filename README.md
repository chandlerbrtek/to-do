# to-do

A basic to-do app that runs in the browser.

## Features

- Add tasks
- Check tasks off as done
- Delete tasks
- Tasks are saved in your browser (localStorage), so they're still there after a reload

## Running it

No build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Hosting

The app is plain HTML, CSS and JavaScript, so it can be hosted on GitHub Pages straight from the repo root.
